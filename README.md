# 📊 Customer Churn Intelligence Dashboard

An interactive data analytics dashboard built with **Python, Streamlit, Pandas, and Plotly** to explore customer churn patterns and understand customer behaviour through visualizations.

## 🚀 Project Overview

Customer churn is an important business challenge because losing customers can affect revenue and long-term growth. This project helps users explore customer data, identify churn patterns, and understand how customer characteristics relate to churn.

The dashboard transforms a customer churn dataset into an interactive interface for data exploration and visualization.

## ✨ Features

- **Interactive Dashboard:** Explore customer churn data through a user-friendly Streamlit interface.
- **Key Performance Indicators:** View summary metrics for the dataset.
- **Churn Analysis:** Explore churn patterns across different contract types.
- **Data Visualization:** Interactive charts built with Plotly.
- **Customer Filters:** Filter customer records to explore specific segments.
- **Customer Data Table:** View filtered customer information.
- **CSV Download:** Download the displayed customer data for further analysis.
- **Exploratory Data Analysis:** Examine distributions of monthly charges and customer tenure.

## 🛠️ Tech Stack

- **Python** — Core programming language
- **Streamlit** — Interactive web application
- **Pandas** — Data manipulation and analysis
- **Plotly** — Interactive data visualizations

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd churn-intelligence-dashboard
```

Replace `YOUR_GITHUB_REPOSITORY_URL` with your repository's HTTPS URL.

### 2. Create and activate a virtual environment (optional but recommended)

```bash
python -m venv .venv
```

On Windows:

```bash
.venv\Scripts\activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the dashboard

```bash
streamlit run app.py
```

The application will open in your browser, usually at `http://localhost:8501`.
